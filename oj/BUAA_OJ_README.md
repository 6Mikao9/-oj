# 北航复试 OJ 系统 - 使用指南

## 系统特点

✅ **按年份组织题目** - 2006-2025 历年真题  
✅ **提交记录追踪** - 每次提交都有记录  
✅ **学习笔记** - 记录每道题的心得  
✅ **进度统计** - 可视化学习进度  
✅ **代码审阅** - 方便我帮你检查代码  

## 快速开始

### 1. 初始化系统

双击运行：
```
init_buaa.bat
```

### 2. 启动图形界面

双击运行：
```
RUN_GUI.bat
```

或者命令行：
```bash
python buaa_gui.py
```

### 3. 添加题目

**方式一：发给我题目图片**
- 把历年真题图片发给我
- 我会帮你：
  - 提取题目信息
  - 创建测试用例
  - 添加到系统中

**方式二：手动添加（命令行）**
```bash
# 创建题目
python buaa_oj.py create 2017 1 "题目名称"

# 添加测试用例
python buaa_oj.py add_test 2017_1 input.txt output.txt
```

## 工作流程

### 日常练习流程

```
1. 打开 GUI (RUN_GUI.bat)
   ↓
2. 选择年份和题目
   ↓
3. 编写代码
   ↓
4. 选择代码文件 → 测试运行
   ↓
5. 如果通过 → 正式提交
   ↓
6. 记录学习笔记
   ↓
7. 继续下一题
```

### 获取帮助流程

```
1. 遇到难题
   ↓
2. 把代码发给我
   ↓
3. 我查看你的提交记录
   ↓
4. 提出修改建议
   ↓
5. 你修改后重新提交
```

## 界面说明

### 左侧：题目列表
- **年份筛选** - 选择特定年份
- **状态筛选** - 查看未解决/尝试中/已解决
- **题目列表** - 显示所有题目和状态
- **进度统计** - 显示总体完成度

### 右侧：题目详情
- **题目信息** - 标题、年份、状态
- **题目描述** - 题目内容
- **学习笔记** - 记录心得
- **代码提交** - 选择代码文件并提交
- **提交历史** - 查看以往提交记录

## 命令行使用

### 常用命令

```bash
# 列出所有题目
python buaa_oj.py list

# 列出某年题目
python buaa_oj.py list 2017

# 查看题目详情
python buaa_oj.py show 2017_1

# 提交代码
python buaa_oj.py submit 2017_1 mycode.cpp

# 添加笔记
python buaa_oj.py note 2017_1 "这道题的难点是..."

# 添加标签
python buaa_oj.py tag 2017_1 "字符串,排序"

# 查看统计
python buaa_oj.py stats

# 导出进度报告
python buaa_oj.py export
```

## 学习建议

### 第一阶段：基础练习（考前2-3个月）
- 每天 2-3 道题
- 重点：字符串、数组、简单模拟
- 目标：熟悉 OJ 系统，掌握基础算法

### 第二阶段：算法强化（考前1个月）
- 每天 1-2 道题
- 重点：DFS/BFS、动态规划、贪心
- 目标：掌握核心算法

### 第三阶段：真题演练（考前2周）
- 每天 1 套真题
- 限时完成
- 目标：适应考试节奏

## 注意事项

1. **代码规范**
   - 使用标准输入输出
   - 注意数据范围
   - 添加必要注释

2. **提交习惯**
   - 先测试运行，确认通过再正式提交
   - 每次提交添加备注（如"第一次尝试"、"修复边界问题"）

3. **备份数据**
   - data/ 目录包含所有学习记录
   - 建议定期备份
