# 2007_3: 多项式相加

【问题描述】
实现两个多项式相加。
多项式用链表表示，每个节点包含系数(coef)和指数(expn)。

## 输入格式
第一行：第一个多项式的项数 n。
接下来 n 行：每行两个整数，表示系数和指数（按指数降序）。
接下来一行：第二个多项式的项数 m。
接下来 m 行：每行两个整数，表示系数和指数（按指数降序）。

## 输出格式
输出相加后的多项式字符串。
系数为 0 的项不输出；系数为 1 时可省略 1；指数为 0 时不输出 x。

## 样例输入
```
3
3 2
2 1
1 0
2
4 2
1 1
```

## 样例输出
```
7x^2+3x+1
```

【解释】
(3x^2+2x+1) + (4x^2+x) = 7x^2+3x+1

【提示】
- 使用链表存储多项式
- 相同指数的项系数相加
- 注意系数为0时要删除该节点
- 输出格式：ax^n+bx^m+...（降幂排列）
