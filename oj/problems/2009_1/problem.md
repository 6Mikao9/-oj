# 2009_1: 立方根逼近迭代

【问题描述】
立方根的逼近迭代方程是：y(n+1) = y(n)*2/3 + x/(3*y(n)*y(n))
其中 y0 = x，求给定的x经过n次迭代后立方根的值。

【输入格式】
多组数据，每组一行两个数：x n
- x：待求立方根的数（double）
- n：迭代次数（int）

【输出格式】
每组数据输出一行，迭代n次后的立方根值
double精度，保留小数点后6位

【样例输入】
3000000 28

【样例输出】
144.224957

【提示】
- 初始值 y0 = x
- 迭代公式：y = y * 2.0 / 3.0 + x / (3.0 * y * y)
- 注意浮点数精度问题
- 立方根迭代收敛很快，28次迭代足够精确
