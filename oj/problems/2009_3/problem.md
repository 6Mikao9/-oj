# 2009_3: 字符串查找删除

【问题描述】
给定多行文本数据和一个待删除的字符串。
要求从文本中删除所有出现的该字符串（不区分大小写），
删除后把每行剩余的空格全部提前至行首，输出处理后的文本。

## 输入格式
第一行：整数n（文本行数）
接下来n行：每行一个字符串（文本内容）
接下来一行：待删除的字符串（无空格）

## 输出格式
输出n行处理后的文本
- 删除所有匹配的子串（不区分大小写）
- 剩余的空格全部提前至行首
- 如果没有匹配，原样输出（空格位置不变）

## 样例输入
```
3
#include <stdio.h>
int main()
printf("Hi ");
In
```

## 样例输出
```
#clude <stdio.h>
t ma()
printf("Hi ");
```

【解释】
删除"In"（不区分大小写，所以删除了"in", "In", "iN", "IN"）
第一行："#include"删除"In" → "#clude"
第二行："int main()"删除"In" → "t ma()"
第三行：没有"In"子串，但注意原样输出

【提示】
- 匹配时不区分大小写
- 删除后把剩余的空格移到行首
- 注意连续匹配的情况
