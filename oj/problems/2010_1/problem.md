# 2010_1: 泰勒公式求cos(x)

【问题描述】
利用泰勒公式求cos(x)的近似值。
cos(x) = 1 - x²/2! + x⁴/4! - x⁶/6! + ... + (-1)ⁿ * x²ⁿ/(2n)!

当某项的绝对值小于给定的精度epsilon时停止迭代。

【输入格式】
第一行：x（弧度，double类型）
第二行：epsilon（精度，double类型，如1e-6）

【输出格式】
输出cos(x)的近似值，保留10位小数

【样例输入】
1.0
1e-6

【样例输出】
0.5403023059

【提示】
- 阶乘增长很快，注意溢出问题，用double存储
- 递推公式：term(n+1) = -term(n) * x² / ((2n+2)*(2n+1))
- 初始值：term(0) = 1
- 注意：比较时用fabs(term) >= epsilon
