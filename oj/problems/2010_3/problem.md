# 2010_3: 判断数组是否完全相同

【问题描述】
两个整数数组（无序，可有重复元素），判断两个整数数组是否完全相同。
（重复元素的重复次数也要相同）

【输入格式】
第一行：整数n（第一个数组的长度）
第二行：n个整数（第一个数组的元素）
第三行：整数m（第二个数组的长度）
第四行：m个整数（第二个数组的元素）

【输出格式】
如果两个数组完全相同，输出"equal!"
否则输出"not equal!"

【样例输入】
4
1 2 2 3
4
2 1 3 2

【样例输出】
equal!

【样例输入2】
3
1 2 3
3
1 2 2

【样例输出2】
not equal!

【提示】
- 两个数组相同：长度相同，且每个元素出现的次数相同
- 不需要排序，直接统计每个元素的出现次数即可
- 可以用map或数组统计频次
