# 2012_3: 统计关键字出现位置

【问题描述】
输入一行标准C语言代码（字符个数小于300），
统计该字符串中关键字if、while、for所在的位置，
按照关键字出现的顺序依次输出。
注意双引号内的不需要统计。

【输入格式】
一行标准C语言代码，字符个数小于300

【输出格式】
关键字if、while、for对应的位置，按照关键字出现的顺序依次输出。
输出格式为：关键字，后跟冒号，然后是出现的位置。
扫描到关键字就输出，每个输出占一行。

【样例输入】
#include <stdio.h> int main() { int i = 0; if(i == 0) printf("YES"); return 0;}

【样例输出】
if:43

【样例说明】
从字符串开头开始计数（从1开始），
关键字if出现在位置43。

【提示】
1. 首先把输入字符串切分为一个个的单词，然后对每个单词进行匹配
2. 注意C语言中的strtok函数不能够返回位置，所以不能满足本题要求，必须自己写获取单词的函数
3. 因为考虑到引号的问题，首先对输入字符串进行预处理，将引号内的每个字符都替换为#，然后再进行单词分割
4. 一次获取源码中的单词，看是否为查找的关键词，如果是则输出
