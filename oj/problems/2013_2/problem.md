# 2013_2: 八皇后问题

【问题描述】
八皇后问题是一个经典的回溯法问题。在8×8的棋盘上放置8个皇后，使其不能互相攻击。
即任意两个皇后不能在同一行、同一列或同一对角线上。

本题要求输出八皇后问题的总解个数。

【输入格式】
无输入

【输出格式】
一个整数，表示八皇后问题的解的个数

【样例输出】
92

【提示】
1. 使用回溯法，从第一行开始逐行放置皇后
2. 维护三个状态数组：列占用、主对角线占用、副对角线占用
3. 对于每一行，尝试在每一列放置皇后，检查是否与之前放置的皇后冲突
4. 如果放置成功，递归到下一行；如果所有列都尝试完毕，回溯到上一行
