# 2013_3: 科学计数法

【问题描述】
给出一个标准输入的正数（开头末尾没有多余的0），要求输出其科学计数法表示结果。

科学计数法格式：AeB，其中1<=A<10，A包含所有有效数字，B为整数指数。

## 输入格式
一个正数（可能包含小数点，长度不超过200）

## 输出格式
科学计数法表示的结果

## 样例输入
```
0.000002
```

## 样例输出
```
2e-6
```

【样例输入2】
123.456

【样例输出2】
1.23456e2

【样例输入3】
123456

【样例输出3】
1.23456e5

【提示】
1. 找到第一个非零数字，确定小数点位置和指数B
2. 如果是整数（不含小数点），指数B为数字总位数减1
3. 如果是小数，指数B为原小数点移动到第一个非零数字后的位数，向右移为正，向左移为负
