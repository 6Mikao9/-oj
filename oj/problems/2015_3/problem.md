# 2015_3: 统计词语

【问题描述】
输入一段含标点的英文语段（若干行，以Ctrl+Z结束，即EOF）
统计这段话中出现的所有词语
要求按字典顺序输出词语，每输出一个词换一行
相同的词语只出现一次（去重）

## 输入格式
若干行英文文本（以EOF结束）

## 输出格式
按字典序排序的不重复单词列表，每行一个单词

## 样例输入
Hello, world! This is a test.
Hello again.

## 样例输出
a
again
hello
is
test
this
world

【提示】
1. 标点符号包括：, . ? ! ; : ' " ( ) [ ] { } < > 
 	 等
2. 将标点符号替换为空格或作为分隔符
3. 将所有字母转换为小写
4. 提取单词，去重，排序后输出
5. 使用选择排序或qsort对单词排序
