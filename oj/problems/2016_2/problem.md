# 2016_2: 解析enum定义

【问题描述】
给一个C语言的enum定义语句，输出enum中规定的各项值。

enum的语法格式：
enum 类型名 { 标识符1[=值1], 标识符2[=值2], ... };

如果没有指定值，则第一个标识符值为0，后面依次递增1。
如果指定了值，则从该值开始，后面依次递增1。

## 输入格式
一行，包含一个enum定义语句

## 输出格式
每行输出一个标识符及其对应的值，格式：标识符 值

## 样例输入
enum BOOL{true,false};

## 样例输出
true 0
false 1

补充样例：
- 输入：enum date{JAN=1,FEB,MAR,APR,MAY,JUN,JULY,AUG,SEP,OCT,NOV,DEC,MON=1,TUE,WED,THU,FRI,SAT,SUN,found=1949};
- 输出：JAN 1 ... found 1949

【提示】
1. 提取花括号内的内容
2. 按逗号分割各项
3. 每项可能有"=值"，也可能没有
4. 没有指定值的项，值为上一项+1（第一项为0）
5. 跳过空格和换行
