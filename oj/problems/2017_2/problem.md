# 2017_2: C变量声明解析

## 问题描述
编写一个程序，从C语言变量声明语句中提取所有变量名。程序需要能够处理复杂的变量声明格式，包括类型限定符、指针、数组等。

## 输入格式
一行C语言变量声明语句
- 可能包含的类型：const, unsigned, signed, short, long, int, char, float, double, void
- 可能包含的修饰符：*, [], 空格
- 多个变量用逗号分隔

## 输出格式
每行输出一个提取到的变量名，按声明顺序输出

## 处理规则
1. 跳过所有类型关键字和限定符
2. 跳过指针(*)和数组([])修饰符
3. 识别有效的变量名（以字母或下划线开头，包含字母、数字、下划线）
4. 支持多个变量的声明（用逗号分隔）

## 样例输入
```
const unsigned long int *ptr, arr[10], var_name, **double_ptr
```

## 样例输出
```
ptr
arr
var_name
double_ptr
```
