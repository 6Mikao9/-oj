# 2017_3: 二叉树族谱

## 问题描述
给定一个二叉树的族谱，查询两个节点的公共祖先以及两个节点相差的层数。

## 输入格式
- 第一行：一个整数N，表示节点数量
- 第二行：根节点的名字
- 接下来N-1行：每行两个名字，表示父子关系（父 子）
- 最后一行：两个名字，表示要查询的两个节点

## 输出格式
一行，格式为：公共祖先：XXX，两节点相差层数：Y

## 样例输入
```
7
ZhangSan
ZhangSan LiSi
ZhangSan WangWu
LiSi ZhaoLiu
LiSi SunQi
WangWu ZhouBa
WangWu WuJiu
WangWu ZhaoLiu
```

## 样例输出
```
公共祖先：ZhangSan，两节点相差层数：1
```

## 提示
- 需要先构建二叉树结构，记录每个节点的父节点和层数
- 使用LCA（最近公共祖先）算法查找公共祖先
- 层数差 = |节点1层数 - 节点2层数|
