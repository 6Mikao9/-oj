# 2018_1: 线段连接

## 问题描述
给定一定数量的线段，线段的右点的横坐标必然比左点的横坐标大。
输入n，以后输入n行，每行为左右点的横纵坐标；
一些线段可以连在一起，输出连在一起的大线段最多有多少条线段，以及最大线段的起点。

## 输入格式
第一行：整数n，表示线段数量
接下来n行：每行4个整数 x1 y1 x2 y2，表示线段左端点和右端点坐标

## 输出格式
三个整数：maxCount maxStartX maxStartY
- maxCount：连在一起的最多线段数
- maxStartX, maxStartY：最大线段的起点坐标

## 样例输入
```
5
0 0 2 2
2 2 4 4
1 1 3 3
3 3 5 5
0 0 1 1
```

## 样例输出
```
3 0 0
```

## 说明
线段(0,0)-(2,2)、(2,2)-(4,4)可以连接，共2条
线段(1,1)-(3,3)、(3,3)-(5,5)可以连接，共2条
线段(0,0)-(1,1)单独1条
最多3条线段的链：(0,0)-(2,2)-(4,4) 实际不是这样...

实际上使用Hash表存储端点，如果新线段的起点匹配已有线段的终点，则合并
