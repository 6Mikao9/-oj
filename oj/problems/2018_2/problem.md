# 2018_2: 三叉树燕子筑巢

## 问题描述
燕子喜欢在稳定的地方筑巢。在三叉树中，节点的稳定性由两个因素决定：
1. 直接子节点数量：子节点越多越稳定
2. 节点深度：深度越大（离根节点越远）位置越隐蔽

给定一个三叉树，需要找到满足以下条件的节点：
- 子节点数量最多
- 如果有多个节点子节点数量相同，选择深度最大的节点
- 如果仍有多个节点满足条件，选择前序遍历中最先遇到的节点

输出该节点的编号及其在前序遍历中的访问次序。

## 输入格式
第一行：整数n，表示在输入中作为父节点出现的节点数量
接下来n行：每行4个整数，格式为 当前节点 左孩子 中孩子 右孩子
- 第一行的节点是根节点
- 孩子节点为0表示该位置无子节点
- 孩子节点不为0表示该位置有子节点（无论该子节点是否在后续输入中作为父节点出现）
- 输入保证每个非根节点的父节点已在之前出现过

## 输出格式
输出两个整数：
目标节点的编号 该节点在前序遍历中的访问次序（从1开始计数）

## 选择规则
1. 优先选择直接子节点数量最多的节点
2. 如果有多个节点子节点数量相同，选择深度最大的节点
3. 如果仍有多个节点满足条件，选择前序遍历中最先遇到的节点

## 样例输入
```
5
100 101 102 103
101 1 0 2
102 3 4 5
103 6 7 0
1 0 0 0
```

## 样例输出
```
102 5
```

## 说明
节点100：子节点3个(101,102,103)，深度1
节点101：子节点2个(1,2)，深度2
节点102：子节点3个(3,4,5)，深度2
节点103：子节点2个(6,7)，深度2
节点1：子节点0个，深度3
节点2,3,4,5,6,7：未作为父节点在输入中出现，子节点数量未知（但根据选择规则，它们不会被选为最优节点）

子节点最多的是100和102（都是3个），在这两个中深度最大的是102（深度2）
前序遍历顺序：100(1)->101(2)->1(3)->2(4)->102(5)->3(6)->4(7)->5(8)->103(9)->6(10)->7(11)
102是第5个访问的节点
