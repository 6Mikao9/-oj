# 2019_1: 素数等差序列

## 问题描述
给定闭区间[a,b]，找出其中所有由**连续素数**构成的等差序列（至少3个素数）。

所谓"连续素数"，指在区间内的素数按从小到大排列后，相邻的素数。若一段连续素数之间的差值全部相同且素数个数 >= 3，则构成一个等差序列。

找出所有这样的**极大等差段**（即不能再向两端扩展），按首元素从小到大依次输出。

## 输入格式
两个整数a和b，表示闭区间[a,b]

## 输出格式
每行输出一个等差序列，序列中的素数用空格分隔。

## 样例输入
```
100 200
```

## 样例输出
```
151 157 163
167 173 179
```

## 说明
[100,200]区间内有两组连续素数等差序列：
- 151 157 163（公差为6，三者之间无其他素数）
- 167 173 179（公差为6，三者之间无其他素数）

再如输入[1,100]会有两个等差序列：
```
3 5 7
47 53 59
```

## 提示
1. 使用筛法预处理素数
2. 注意1不是素数
3. 扫描相邻素数的差值，找出差值相同的极大段
