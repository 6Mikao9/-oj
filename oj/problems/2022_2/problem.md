# 2022_2: 简单编译器模拟

## 问题描述
该程序会模拟一个解释运行的编译系统，每次从标准输入中读入一行指令，都要进行对应的操作。

程序中存在四种语句，语句最长200个字符，每个语句占且仅占一行，每行最多一个语句。

## 四种语句格式

### 1. 输入语句
格式为 `read + 空格 + <变量序列> + 换行符`
- 变量序列是以空格分隔的变量名称的组合
- 变量的名字只可能是单个的小写字母
- 变量不需要提前声明
- 紧接着下一行，输入若干十进制整数，每个整数和上一行的变量对应赋值

### 2. 赋值语句
格式为 `变量 + 等于符号 + 表达式 + 换行符`
- 表达式中包含十进制整数、变量、+-*/() 这六种计算符号
- 整个语句不包含空白符

### 3. 输出语句
格式为 `print + 空格 + <变量序列> + 换行符`
- 紧接着下一行，输出若干个变量的值
- 值以浮点数形式输出，保留两位小数
- 值之间以空格分隔
- 最后一个值后面不跟空格和换行符

### 4. 结束语句
格式为 `exit + 换行符`
- 该语句后直接结束程序运行

## 样例输入
```
read a
10
b=20
c=(a+b)/4
print a b c
exit
```

## 样例输出
```
10.00 20.00 7.50
```

## 提示
- 所有语句均不包含语法错误
- 所有变量在使用前均会赋值
- 不需要考虑输入错误的情况
- 需要实现表达式解析（支持+-*/和括号）

## 输入格式
输入由多行语句构成，直到读到 `exit` 结束。

支持语句：
1. `read <var list>`：下一行读入对应数量的整数赋值给变量。
2. `<var>=<expr>`：赋值语句，`expr` 支持 `+ - * / ()`。
3. `print <var list>`：输出变量值。
4. `exit`：结束程序。


## 输出格式
每条 `print` 语句输出一行。
按请求顺序输出变量值，值之间用一个空格分隔，保留两位小数。
