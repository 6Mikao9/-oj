# 2023_2: 老鼠返回最短路径

## 问题描述
老鼠在二维网格上移动，移动记录为若干个 `方向-步数` 对。
当老鼠找到食物后，需要返回起点，请输出一条最短返回路径。

方向定义：
- `1`：向上
- `2`：向下
- `3`：向左
- `4`：向右

路径化简规则：
1. 相反方向的移动可以相互抵消；
2. 同方向的连续移动需要合并。

## 输入格式
- 输入为一行或多行空白分隔的 `方向-步数` 对；
- 以 `0-0` 结束；
- 保证输入移动记录有效（方向在 1~4，步数为正整数）。

## 输出格式
输出最短返回路径，格式同输入（多个 `方向-步数` 对以空格分隔，不包含 `0-0`）。

若返回路径长度为 0（已在起点），输出 `0-0`。

## 样例输入
```text
1-10 0-0
```

## 样例输出
```text
2-10
```
