# 2024_1: 学生运动记录分类统计

## 问题描述
学校有三类学生：本科生、硕士生、博士生，其学号前缀分别为 `B`、`S`、`M`。
给定若干条运动记录，每条记录包含：
- 学号
- 运动形式（字符串）
- 开始时间（`HHMMSS`）
- 结束时间（`HHMMSS`）

同一学生可能有多条记录。

请将学生按类别（`B`、`S`、`M`）输出，并在每个类别内按“总运动时长”从小到大排序。
每个学生输出学号、总运动时长（单位：小时，保留两位小数）以及该学生出现过的运动形式（英文逗号分隔）。

## 输入格式
- 第一行：整数 `n`，表示运动记录数量。
- 接下来 `n` 行：每行格式为
  `id sport start end`
  其中 `start` 与 `end` 均为 `HHMMSS`（同一天内，且 `end >= start`）。

## 输出格式
按类别顺序 `B`、`S`、`M` 输出。

每个学生输出一行：
`id total_hours sports`

说明：
- `total_hours` 为总运动秒数除以 3600 后保留两位小数；
- 同一学生的 `sports` 去重后按字典序拼接，使用英文逗号 `,` 分隔；
- 同类别中若总时长相同，按学号升序。

## 样例输入
```text
6
B1001 run 080000 090000
B1001 swim 093000 103000
S2001 run 070000 073000
M3001 gym 100000 113000
S2002 bike 080000 100000
B1002 run 060000 063000
```

## 样例输出
```text
B1002 0.50 run
B1001 2.00 run,swim
S2001 0.50 run
S2002 2.00 bike
M3001 1.50 gym
```
