# 2024_2: 网络设备故障传播定位

## 问题描述
网络中有两类设备：
- `0`：交换机
- `1`：电脑

设备组成一棵树（每个设备有一个父设备，根设备父编号为 `-1`）。
若某个交换机故障，则其下游所有设备都可能受到影响。

给定设备信息和一个已知故障交换机编号，请输出所有“可能故障”的设备编号。

## 输入格式
- 第一行：整数 `n`，表示设备数量。
- 接下来 `n` 行：每行四个整数
  `id type port parentId`
  含义分别为：设备号、设备类型、端口号、父设备号。
- 最后一行：整数 `faultySwitchId`，表示已知故障交换机编号。

## 输出格式
按先序遍历（父节点优先，再按子设备编号升序遍历子树）输出可能故障的设备编号，空格分隔。

若无可输出设备，输出空行。

## 样例输入
```text
7
0 0 1 -1
1 0 1 0
2 1 1 1
3 1 2 1
4 0 1 0
5 1 1 4
6 1 2 4
1
```

## 样例输出
```text
1 2 3
```
