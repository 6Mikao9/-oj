# 2025_2: 找出最合适的基站

## 问题描述
在城市道路网络中，输入 `n` 条双向道路，每条道路给出两个端点城市和长度。
需要找出一个“出发城市”，使其到其余所有城市的最短路径长度之和最小。
题目保证这样的城市唯一。

## 输入格式
- 第一行：整数 `n`，表示道路条数。
- 接下来 `n` 行：每行 3 个字段
  `city1 city2 w`
  表示城市 `city1` 与 `city2` 之间有一条长度为 `w` 的双向道路。

## 输出格式
输出两项：
`bestCity minSum`
其中 `minSum` 为该城市到所有城市最短路径长度之和。

## 样例输入
```text
5
C1 C4 100
C3 C6 120
C4 C5 300
C6 C1 230
C2 C5 300
```

## 样例输出
```text
C1 1780
```
