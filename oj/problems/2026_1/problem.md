# 2026_1: 2026-模拟

## 问题描述
给定一个只包含非负整数、运算符 `+ - * /`、圆括号 `(` `)` 的中缀表达式，计算其结果。

要求遵循标准运算优先级：
- 先算括号内
- 再算乘除
- 最后算加减
- 同一优先级从左到右计算

## 输入格式
一行字符串，表示表达式 `expr`。

约束：
- `1 <= expr.length <= 200`
- 表达式合法
- 只包含非负整数和上述运算符/括号，可包含空格
- 不会出现除以 0

## 输出格式
输出表达式计算结果，保留 2 位小数。

## 样例输入
```text
(5+6)/4
```

## 样例输出
```text
2.75
```
