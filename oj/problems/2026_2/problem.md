# 2026_2: 文件系统目录管理

## 问题描述

文件系统以树形结构组织,根目录为 `/`。每个节点是**目录**或**文件**,一个目录下可以包含若干子目录和文件(同一目录下名字不重复)。每个文件有一个字节大小,目录自身不占空间(大小为 0)。

初始给定一棵目录树,随后进行一系列操作,涉及对文件/目录的**增删改查**:

- **增**:创建目录、创建文件
- **删**:删除文件或目录(删除目录时递归删除其全部内容)
- **改**:移动/重命名
- **查**:查询某路径的子树总大小

所有操作结束后,输出**最终的目录树结构**。

## 输入格式

第一行:整数 `n`,表示初始目录树中的节点个数。

接下来 `n` 行,每行描述一个节点:`路径 类型 大小`
- `路径`:从根开始的形式为 `/a/b/...` 的绝对路径。约定路径中每个名字不含 `/` 与空格,目录路径可带也可不带末尾 `/`。
- `类型`:`D` 表示目录,`F` 表示文件。
- `大小`:文件大小(非负整数);目录固定为 `0`。
- 保证输入是合法的树:父节点先于子节点出现,同一目录下名字不重复,且**根目录 `/` 已在其中,其大小为 0、类型为 D**。

接下来一行:整数 `m`,表示操作个数。

接下来 `m` 行,每行一个操作,格式如下:

| 操作 | 含义 | 说明 |
|------|------|------|
| `mkdir 路径` | 创建目录 | 若路径已存在或父目录不存在,忽略 |
| `create 路径 大小` | 创建文件 | 若路径已存在或父目录不存在,忽略 |
| `rm 路径` | 删除节点 | 目录递归删除;若不存在或为根目录,忽略 |
| `mv 源路径 目标路径` | 移动/重命名 | 见下方约定;非法则忽略 |
| `size 路径` | 查询子树大小 | 输出结果 |

**`mv` 约定**:
- 若 `目标路径` 指向一个**已存在的目录**,则将 `源路径` 移入该目录下,保持原名。
- 否则,将 `源路径` 重命名并移动为 `目标路径`(其父目录必须存在)。
- 非法情况(源不存在、目标父目录不存在、目标已存在、将目录移入自身或其子目录中)一律忽略。

**`size` 查询**:输出 `路径` 对应节点子树中所有文件大小之和(目录含全部子孙;文件即自身)。若路径不存在,输出 `-1`。

## 输出格式

- 每个 `size` 操作输出一行整数(顺序与操作顺序一致)。
- 最后输出**最终目录树结构**:
  - 根目录 `/` 单独占一行;
  - 每个节点一行,缩进 = 深度 × 2 个空格;
  - 目录行:`名字/`;文件行:`名字 大小`;
  - 同一目录下的子节点按**名字 ASCII 字典序**排列。

## 样例输入

```text
6
/ D 0
/etc D 0
/etc/passwd F 100
/etc/nginx D 0
/home D 0
/home/user D 0
7
mkdir /var
create /var/log.txt 50
size /etc
rm /etc/nginx
mv /home/user /home/student
create /home/student/notes.txt 10
size /home
```

## 样例输出

```text
100
10
/
  etc/
    passwd 100
  home/
    student/
      notes.txt 10
  var/
    log.txt 50
```

## 数据范围

- `1 <= n <= 1000`, `1 <= m <= 5000`
- 路径长度 <= 100,文件大小 <= 10^6
- 名字由字母、数字、点、下划线、连字符组成,不含 `/` 与空格
