# 2026_2: 窗口点击叠放模拟

## 问题描述
有 n 个窗口，输入顺序表示从上到下的初始叠放顺序（先输入的在更上层）。
每次鼠标点击会命中最上层且包含点击点的窗口，该窗口会被提升到最上层。
请输出所有点击结束后的窗口叠放顺序（从上到下）。

## 输入格式
- 第一行：整数 n（1 <= n <= 100）
- 接下来 n 行：`id x1 y1 x2 y2`，表示窗口编号与矩形区域
- 下一行：整数 m（1 <= m <= 1000）
- 接下来 m 行：`x y` 表示点击坐标

说明：边界也算命中。

## 输出格式
一行，按从上到下输出窗口 id，空格分隔。

## 样例输入
```text
3
1 0 0 4 4
2 2 0 6 4
3 5 0 8 4
3
3 2
6 2
1 1
```

## 样例输出
```text
1 3 2
```
