# 2026_4: 三叉树稳定节点

## 问题描述
给定一棵三叉树的父节点输入，要求找出“最稳定”节点。
稳定性规则：
1. 直接孩子数量越多越优先；
2. 若孩子数量相同，深度更大者优先；
3. 若仍相同，按前序遍历先访问者优先。

输出该节点编号和其前序序号（从 1 开始）。

## 输入格式
- 第一行：整数 n（作为父节点出现的节点数）
- 接下来 n 行：`id left mid right`，孩子为 0 表示空

## 输出格式
一行两个整数：`node_id preorder_index`

## 样例输入
```text
4
100 101 102 103
101 1 0 2
102 3 4 5
1 0 0 0
```

## 样例输出
```text
102 5
```
