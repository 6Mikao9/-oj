# 2026_7: 文本关键词删除与空格前移

## 问题描述
给定 n 行文本和一个待删除字符串 key。
对每一行执行：
1. 删除所有与 key 大小写无关匹配的子串；
2. 将该行剩余的空格字符全部移动到行首，其他字符相对顺序不变。

## 输入格式
- 第一行：整数 n
- 接下来 n 行：文本
- 最后一行：key

## 输出格式
输出 n 行处理后的文本。

## 样例输入
```text
3
#include <stdio.h>
int main()
printf("Hi ")
In
```

## 样例输出
```text
#clude <stdio.h>
 tma()
printf("Hi ")
```
