# 2026_8: 学生运动记录汇总

## 问题描述
每条记录包含：学号、运动项目、开始时间、结束时间（HHMMSS）。
请按学号汇总每位学生的：
- 总运动时长（小时，保留 2 位小数）
- 参与项目集合（按字典序，逗号分隔）

输出按总时长降序，若相同按学号升序。

## 输入格式
- 第一行：整数 n
- 接下来 n 行：`stu_id sport start end`

## 输出格式
每行：`stu_id total_hours sports`

## 样例输入
```text
4
1001 run 083000 093000
1002 swim 090000 100000
1001 bike 101500 111500
1002 run 101000 103000
```

## 样例输出
```text
1001 2.00 bike,run
1002 1.50 run,swim
```
