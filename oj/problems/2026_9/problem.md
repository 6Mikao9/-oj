# 2026_9: 简易脚本解释器

## 问题描述
实现一个简化解释器，支持四类语句：
- `read a b c`：下一行读取对应整数
- `x=expr`：表达式赋值，支持 `+ - * / ()`
- `print a b c`：输出变量值，保留 2 位小数
- `exit`：结束

变量名均为单个小写字母，输入保证语法合法。

## 输入格式
多行脚本，直到 `exit`。

## 输出格式
每遇到一条 `print`，输出一行对应值。

## 样例输入
```text
read a b
10 20
c=(a+b)/4
print a b c
exit
```

## 样例输出
```text
10.00 20.00 7.50
```
