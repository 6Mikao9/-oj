一、系统介绍
------------
本系统是一个本地 C++ 代码评测系统，帮助你准备北航研究生复试上机考试。

主要功能：
✓ 题目管理：创建题目、添加测试用例
✓ 自动评测：编译、运行、对比输出
✓ 结果反馈：显示通过情况和错误信息


二、快速开始
------------

1. 双击运行 "启动OJ.bat"，选择操作

2. 或者在命令行中：
   
   # 初始化示例题目
   python init_problem.py
   
   # 启动图形界面
   python oj_gui.py
   
   # 命令行评测
   python oj_system.py judge tamworth_two 你的代码.cpp


三、文件说明
------------

oj_system.py      - 核心评测系统（命令行）
oj_gui.py         - 图形界面程序
init_problem.py   - 初始化示例题目
quick_test.py     - 快速测试脚本
启动OJ.bat        - Windows 快速启动
buaa_problems.py  - 北航题目合集

目录结构：
oj/
├── problems/         # 题目目录
│   └── tamworth_two/ # 示例题目
│       ├── info.json     # 题目信息
│       ├── testcases/    # 测试用例
│       │   ├── 1.in
│       │   └── 1.out
│       └── solution.cpp  # 参考解答
├── submissions/      # 提交记录
└── temp/             # 临时文件


四、使用流程
------------

1. 当我给你新题目时：
   
   你把题目图片发给我
       ↓
   我帮你分析题目、构建测试用例
       ↓
   题目自动添加到你的 OJ 系统
       ↓
   你写代码并在 OJ 上评测
       ↓
   根据反馈修改直到通过


2. 自己添加题目：
   
   方法A - 图形界面：
   - 运行 python oj_gui.py
   - 左侧输入题目ID和名称，点击"创建题目"
   - 输入测试数据，点击"添加测试用例"
   
   方法B - 命令行：
   - python oj_system.py create 题目ID 题目名称
   - 手动在 problems/题目ID/testcases/ 目录下创建 .in 和 .out 文件


3. 评测代码：
   
   方法A - 图形界面：
   - 选择题目
   - 选择代码文件
   - 点击"开始评测"
   
   方法B - 命令行：
   - python oj_system.py judge 题目ID 代码文件.cpp


五、评测结果说明
----------------

✓ AC (Accepted)      - 通过，答案正确
✗ WA (Wrong Answer)  - 答案错误，输出不符合预期
⏱ TLE (Time Limit)   - 运行超时，超过1秒限制
💾 MLE (Memory Limit) - 内存超限
⚠ RE (Runtime Error) - 运行时错误（数组越界、除零等）
🔧 CE (Compile Error) - 编译错误


六、北航复试准备建议
--------------------

1. 基础练习（每天2-3题）
   - 字符串处理
   - 数组操作
   - 简单数学问题

2. 核心算法（重点掌握）
   - DFS/BFS 搜索
   - 动态规划

   - 二分查找

3. 数据结构
   - 栈、队列、链表
   - 树和图的遍历
   - 并查集

4. 注意事项
   - 使用标准输入输出
   - 注意数据范围，选择合适的数据类型
   - 考虑边界情况
   - 代码要清晰、有注释


七、常见问题
------------

Q: 编译错误怎么办？
A: 检查是否使用了 C++17 特性，确保代码能在 g++ 下编译

Q: 答案错误但看起来是对的？
A: 检查是否有：
   - 多余的空格或换行
   - 大小写错误
   - 输出格式不匹配

Q: 运行超时怎么办？
A: 优化算法，降低时间复杂度

Q: 如何添加更多测试用例？
A: 编辑 init_problem.py 或在图形界面中直接添加
